This tutorial guides you through installing, building, and running the `credentio validate` command-line tool across **Python**, **Go**, and **Swift**.

---

## 1. Getting a Sample C2PA Asset

To test content credential verification, you can use any C2PA-signed media file or download sample assets from the [C2PA Public Conformance Samples](https://github.com/c2pa-org/conformance-public/tree/main/test-fixtures) or [Content Authenticity Initiative (CAI) test files](https://github.com/contentauth/c2pa-rs/tree/main/sample).

```bash
# Example: download a public C2PA test image
curl -sLO https://raw.githubusercontent.com/c2pa-org/conformance-public/main/test-fixtures/image/image_signed.jpg
```

## 3. Standard Exit Codes

All three command-line tools implement standard Unix exit codes for shell scripting and CI automation:

| Exit Code | Meaning | Shell Status |
| :---: | :--- | :--- |
| **`0`** | **`SIGNED`** | Valid C2PA credentials found and verified. |
| **`1`** | **`UNSIGNED`** | Media asset is authentic but has no C2PA manifest attached. |
| **`2`** | **`INVALID`** | C2PA manifest found, but validation reported one or more integrity/signature errors. |
| **`3+`** | **`ERROR`** | Missing file, invalid command arguments, or internal engine failure. |

### Shell Scripting Example
```bash
credentio validate upload.jpg --json > result.json
EXIT_CODE=$?

if [ $EXIT_CODE -eq 0 ]; then
  echo "Asset has verified C2PA Content Credentials!"
elif [ $EXIT_CODE -eq 1 ]; then
  echo "Asset has no C2PA credentials."
elif [ $EXIT_CODE -eq 2 ]; then
  echo "WARNING: Asset failed C2PA validation checks!"
else
  echo "Validation failed with execution error."
fi
```
