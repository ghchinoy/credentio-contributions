## What is Google Credentio?

As media provenance standards and transparency regulations take effect worldwide, verifying the origin and history of digital assets is essential for modern software.

[Google Credentio](https://mediaprovenance.googlesource.com/credentio/) is an open-source C++ library for validating [C2PA (Coalition for Content Provenance and Authenticity)](https://c2pa.org/) Content Credentials across images, videos, audio, and documents. As highlighted in the [Google Developers Blog announcement](https://developers.googleblog.com/introducing-credentio-open-source-c-library-for-c2pa-content-credentials-from-google/), this is the exact engine running at scale across nearly 40 conformant Google products.

## What This Project Provides

Credentio is authored in C++20 with Bazel. **Credentio Contributions** bridges the C++ core into a universal C-ABI bridge, delivering first-class language bindings for developers working in Python, Go, and Swift.

```text
┌───────────────────────────┐  ┌───────────────────────────┐  ┌───────────────────────────┐
│     Python (credentio)    │  │     Go (credentio/go)     │  │    Swift (CredentioKit)   │
│  - cffi dynamic binding   │  │  - cgo native binding     │  │  - Actor-isolated Swift   │
│  - Typed dataclasses      │  │  - Idiomatic Go structs   │  │  - Static XCFramework     │
└─────────────┬─────────────┘  └─────────────┬─────────────┘  └─────────────┬─────────────┘
              │                              │                              │
              └──────────────────────────────┼──────────────────────────────┘
                                             │
                           ┌─────────────────▼─────────────────┐
                           │      libcredentio_c (C-ABI)       │
                           └─────────────────┬─────────────────┘
                                             │
                           ┌─────────────────▼─────────────────┐
                           │      Google Credentio (C++20)     │
                           └───────────────────────────────────┘
```
